# Фаза 4: безкоштовне хмарне розгортання

**Статус:** підготовка до навчального деплою завершена; ресурси ще не створені.

## Мета

Розгорнути перевірену версію StudyPlanner на безкоштовних планах Render і Neon, зберегти same-origin HTTPS та задокументувати URL і результати перевірок. Безкоштовний деплой призначений для навчальної демонстрації й не має production SLA.

- [x] Завершити перегляд поточних змін у робочому дереві.
- [ ] Повторно виконати CI/фінальний набір перевірок на тому самому коді, який буде розгорнуто (локально пройшло на Node 24.13.1; очікується CI на закріпленому Node 22.23.5).
- [ ] Зафіксувати перевірену версію в `main`.
- [x] Звірити актуальні тарифи, ліміти й умови Render та Neon.
- [x] Перевірити актуальні CI-збої й виправити блокери перед deploy.
- [x] Зафіксувати runtime на Node.js 22.23.5 для узгодження Render і CI.

## Підготовка (14.11.2026)

- Локально на Node.js 24.13.1: `npm run lint`, `npm run validate:client`, `npm run secret-scan`, `npm test` (181/181) — пройшли.
- Playwright: 126 пройшли, 62 пропущено; axe-набір виконується лише у Chromium. Chromium і Firefox e2e сценарії пройшли.
- Точну версію Node.js 22.23.5 ще потрібно підтвердити CI після запуску workflow.
- Цільова вартість — $0: Render Free Web Service + Neon Free. Render має холодні старти та квоти; щоб уникнути можливих overage charges, не додавайте до Render workspace платіжний метод. Деталі лімітів наведені в [`../deployment.md`](../deployment.md).

## План виконання

- [ ] Створити Neon Free project/database і зберегти TLS connection string як секрет.
- [ ] Створити Render Web Service на плані Free з коренем репозиторію, `npm ci --prefix server` і `npm start --prefix server`.
- [ ] Налаштувати environment variables, HTTPS, secure session cookie та залишити стандартну TCP health check (не викликати БД періодичним HTTP probe).
- [ ] Застосувати міграції до Neon database; не запускати seed без окремої потреби.
- [ ] Перевірити health endpoint, auth/session, task/discipline CRUD, headers, логи й основні сторінки.
- [ ] Перевірити та задокументувати безпечний відкат.
- [ ] Записати URL навчального деплою, дату, версію коміту й результати у цьому звіті та README.

## Критерії завершення

Фазу можна позначити завершеною, коли free service працює за HTTPS із коректною БД і сесіями, проходить документований smoke-check, а URL і фактичні результати зафіксовані. У README позначати його як навчальний free-tier деплой, не як production-сервіс.

Детальна процедура: [`../deployment.md`](../deployment.md). Архітектурні вимоги: NFR-23 і NFR-24 у [`../requirements.md`](../requirements.md).

# StudyPlanner

Вебзастосунок для планування навчальних завдань і дедлайнів.

Лабораторна робота №4, фаза 2: список завдань працює на JavaScript і зберігає зміни в localStorage.

## Структура

```text
StudyPlanner/
├── index.html                  # Головна сторінка
├── tasks.html                  # Список завдань
├── tasks-*.html                # Короткі переходи до станів tasks.html
├── calendar.html               # Календар завдань
├── calendar-*.html             # Стани фільтрації календаря
├── login*.html                 # Вхід і стан помилки
├── register*.html              # Реєстрація і стан помилки
├── 404.html, 500.html, offline.html # Сторінки системних помилок
├── states.html                 # Каталог станів інтерфейсу
├── js/                         # Звичайні defer-скрипти без модулів
├── css/
│   ├── tokens.css              # Кольори, розміри, відступи
│   ├── base.css                # Базові стилі та шрифти
│   ├── layout.css              # Загальні макети
│   ├── components.css          # Спільні UI-компоненти
│   ├── utilities.css           # Допоміжні класи
│   └── pages/                  # Стилі окремих сторінок
└── assets/
    └── fonts/                  # Локальні файли Geist
```

## Запуск

Двічі клацніть `index.html` і перейдіть до завдань. Сайт працює через `file://`, без сервера, збірки, npm-залежностей і CDN. Для списку завдань потрібен JavaScript. Навігація, details/summary та посилання на діалоги зберігають базову HTML-поведінку без JavaScript.

`states.html` відкриває демонстраційні стани через `tasks.html?state=...`. Ці стани використовують тимчасову копію початкових даних і не змінюють ваші збережені завдання. Звичайна `tasks.html` працює зі сховищем браузера.

## Демо-дата та скидання

У `js/dates.js` встановлено `USE_DEMO_DATE = false`: усі дати спираються на today() і реальну локальну дату. Для порівняння з Figma встановіть true — today() поверне 06.10.2026, seed матиме початкові фіксовані дати.

Щоб відновити сім початкових завдань і скинути фільтри, відкрийте звичайну `tasks.html` та виконайте в консолі браузера:

```js
StudyPlanner.storage.reset();
```

Це замінить ваші завдання початковими. Ключі: `studyplanner.tasks.v2` і `studyplanner.settings.v1`. Якщо браузер забороняє localStorage, список працює в пам’яті до перезавантаження. Сховище `file://` залежить від браузера та розташування файлу; перенесення папки може створити окреме сховище.

## Що використано

HTML5, CSS3 (Flexbox, Grid, змінні, медіазапити, `:target`, переходи й анімації), JavaScript і локальний шрифт Geist. Список і календар фільтруються JavaScript; статичні дублікати видалені.

## Як це зроблено

- Стилі поділені на загальні (`base`, `layout`, `components`, `utilities`) і сторінкові (`css/pages/`). Кольори, розміри й відступи лежать у `css/tokens.css`, тому в компонентах вони не дублюються.
- Верстка підлаштовується під телефон, планшет і широкий екран. Медіазапити є в `css/layout.css` та файлах у `css/pages/`.
- Випадаючі меню використовують `<details>`, діалоги — `:target`. На сторінці завдань JavaScript додає закриття меню, фокус, клавіатуру та зміну даних; картки й порожні стани клонуються з `<template>`.
- Модальні вікна й елементи керування анімовані. Для тих, у кого в системі ввімкнено зменшення руху, анімації вимикаються через `prefers-reduced-motion`.

## Календар та демо-логін

Календар генерує місяці з понеділка, показує завдання зі спільного store, відкриває день і підставляє дату в додавання. Поле дати використовує спільний власний календар і ручне введення дд.мм.рррр.

Демо-логін: **olena.koval@example.com**, пароль **Study2026!**. Реєстрація зберігає локального користувача в `studyplanner.user.v1` (ім’я, email, SHA-256 пароля) і відкриває список. Серверної авторизації немає. Скидання завдань не видаляє користувача; для його видалення виконайте `localStorage.removeItem("studyplanner.user.v1")`.

Після оновлення tasks.v2 замінює лише незмінений старий seed; користувацькі завдання з tasks.v1 переносяться без зміни дат. Seed створюється відносно today() один раз, збережені завдання не пересуваються щодня. `tasks.html#add-task-date` відкриває Add із власним календарем.
